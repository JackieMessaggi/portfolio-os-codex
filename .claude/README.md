# Claude Code setup

Open Claude Code in this project's root folder. `CLAUDE.md` imports the shared project instructions and voice guide, and requires reading the current brief and visual direction.

Skills in this directory are relative symbolic links to `.agents/skills/`, keeping one maintained source for both agents. Use `/case-study`, `/site-brief`, `/visual-direction`, or another project skill in Claude Code. Tools and account connections must be configured separately in each agent.

To check a new session, use `/memory` to inspect loaded instructions and `/` to check available skills. Then ask Claude to summarize the approved direction and pending decisions without editing files.

This setup prepares project files only. It does not install Claude Code, sign in, configure integrations, or verify a live Claude session.

References: [Project instructions](https://code.claude.com/docs/en/memory), [Skills](https://code.claude.com/docs/en/skills).
