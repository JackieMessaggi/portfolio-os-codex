    02 / Concept & validation

    Rules on paper, a game on screen

    The project started as Quiz Arena, a quiz-meets-bingo concept. The product team defined the mechanics and the first five minutes in a game design document, and our PM turned them into low-fidelity wireframes. The priority was speed: a playable prototype to validate the gameplay.

    I translated the wireframes into high-fidelity UI and an interactive Figma prototype of the FTUE. The document introduces one mechanic at a time (the question ball, the card, stars, the End button, lives, the timer), so each screen had to make one idea clear: a tip on Spin, a 3×3 card that reads at a glance, and a first Bingo within reach.

    The first challenge wasn’t building a visual world. It was making the game playable and understandable, so a full identity was deliberately left for later. Once the mechanics took shape, the next challenge was giving them one.

    03 / Designing in stages

    From a prototype to a world

    From there, the project moved toward release in three stages, often with the team working on two at once. Each stage had a different job, and the game’s identity only arrived in the second one.

    04 / Soft launch identity

    Every level is a stop on a trip

    Giving the mechanics an identity was the Soft Launch’s job. The Quiz Arena concept grew into Quiz Bingo World Tour, and I developed its World Tour theme, the logo, and the visual direction. Cities group the levels, each with its own landmark, and every trivia category owns one color and one object, so you know where you are before you read a word.

    05 / From designing to directing

    From storyboard to screen

    In the early stages, I created the motion references myself. While we prepared the Official Release, I advocated bringing a Motion/3D Designer onto the team, and my role shifted to art direction: storyboards to agree on each moment, interactive references for timing, and feedback and visual guidance while the specialist built the final 3D and motion.

    06 / Growing the UI system

    The same pieces, many features

    As the game grew, the same kit kept stretching. Rewards, duels, profiles, feedback, and a shop each reused the same UI components (the popup frame, the ribbon header, the chunky buttons, and one 3D object as the hero), and none of them needed a new visual language.

    07 / Working with Unity

    Built to be built

    Designing for Unity meant designing for implementation. I prepared every screen so our Unity developer could build it without guessing, then answered questions as implementation went along. Each one left Figma with:

    1. an interactive Figma prototype of the flow
    2. a high-fidelity reference screen and a type spec
    3. every layer as a 4× UI asset export
    4. a motion reference for anything that moves

    I exported the same Home for three phone heights and a tablet. On tablet, the stickers spread wider around a larger landmark, so the hierarchy reads the same on every screen.

    08 / What I learned

    My first mobile game

    Feedback is the game

    Quiz Bingo showed me how much of a game’s experience lives in its feedback. Progression, rewards, and celebrations are what make a short session feel worth repeating, so a star landing or a chest opening deserves the same care as any screen.

    Designing with the engine in mind

    A game engine changes when you think about the details. States, assets, and motion have to be considered while a screen is being designed, not after, and technical limits are far easier to design with early than to work around late.

    Knowing when to bring in expertise

    My first mobile game taught me that leading design doesn’t mean executing every part of it. I could create motion references and communicate how an interaction should feel, but I also recognized where my skills had limits. Advocating for a Motion/3D Designer gave the game the expertise it needed and challenged me to grow into art direction: setting a vision, communicating it clearly, and refining the result together.
